#원격 스팀 설치 PoC

개요 : 이 프로젝트는 원격제어 환경에서 대상 컴퓨터에 스팀(Steam)을 자동으로 설치하게 하는 명령을 해서 피해자PC에 설치파일을 다운로드 하게 하는 것을 구현했습니다

구조 : 서버를 열고 피해자 컴퓨터에서 코드가 실행되면 10초마다 서버에서 명령어를 확인해 해당 명령을 수행.

문제점 : 피해자 컴퓨터에 코드 파일이 설치 되었을때 powercell을 관리자 권한으로 열고 코드를 실행시키는 것이 자동화가 되지 않음. 
한번 요청 받은 내용을 계속 수행함. 

계획 : 관리자 권한 상승 자동화로 파일이 설치 되면 은밀하게 실행될 수 있게 바꾼다.
